## Purpose
Establish project governance, principles, and standards that guide all development work on the polyglot GraalVM application.

## Requirements Identified
- Define core principles for development approach
- Establish technology stack requirements
- Set development workflow standards
- Create governance and amendment processes
- Ensure compliance with Test-First methodology

## Context
This prompt led to the creation of the graalvm Constitution v1.0.0 with 5 core principles including Library-First, CLI Interface, Test-First (NON-NEGOTIABLE), Integration Testing, and Observability & Versioning.
